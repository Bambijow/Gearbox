# Gearbox for Antigravity

Native Antigravity App / CLI plugin (preview). Run `agy plugin validate --strict .`, then `agy plugin install .` and verify `/hooks` reports `gearbox-control-plane`.

The existing `.claude-plugin/` stays available for Claude Code. All root `skills/`, `scripts/`, `references/` are shared. See `GEMINI.md` for the migration boundary. This preview does not yet claim full `/issue` workflow compatibility.
