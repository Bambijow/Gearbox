# Visual inspiration and Inspo evidence

External references are evidence and calibration, never templates to clone.

## Inspo sequence

When Inspo is available:

1. start from the real brief with `recommend` or a targeted screen search;
2. pick 2-4 exemplars that illuminate different useful directions;
3. use `compare` when triangulating house style or category gravity;
4. use `get_design_system` only for references worth studying;
5. use component/example search only for a concrete information-structure question.

Avoid exhaustive browsing.

## Evidence packet

Capture:

- selected screen/site identifiers;
- useful macrostructure;
- typography/material/palette disciplines;
- repeated category patterns;
- meaningful outliers;
- one or two anti-references;
- what Gearbox will borrow at the principle level;
- what Gearbox intentionally refuses or changes.

Category consensus is gravity, not law.

## Anti-slop use of evidence

Use Inspo to see the category rut clearly enough to avoid reproducing it unconsciously.

If references converge on the same dark canvas, rounded-card stack, grotesk face, glow treatment or hero formula, record that convergence under `category_rut`. Prefer at least one useful outlier when it reveals another credible way to express the same user job.

Do not average several fashionable sites into a generic composite.

## Reference, do not clone

Do not reproduce another site's identity, layout, copy, imagery or signature interaction wholesale. Adapt principles to the target product.

Good:
- borrow dense editorial hierarchy;
- reuse an information rhythm with different composition;
- reject the category's default violet-gradient card stack.

Bad:
- make it exactly like Linear/Stripe/etc.;
- copy this hero and replace the logo.

When Inspo is unavailable, continue using repository truth, existing screenshots/tokens/components and first-principles design reasoning.
